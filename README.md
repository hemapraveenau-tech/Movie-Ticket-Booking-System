A simple console-based Movie Ticket Booking System developed using Core Python.

 Features:-

-  View available movies
-  View show timings
-  Select and book seats
-  Book movie tickets
-  User and Admin panels
-  View booking details
-  Check seat availability

 Technologies Used:-

- Python
- Lists
- Dictionaries
- Tuples
- Loops
- Conditional Statements
- User Input

 How to Run:-

1. Download or clone the project.
2. Open the Python file.
3. Run the program in a Python environment.
4. Follow the menu options shown on the screen.

 Project Purpose:-

This project was created to practice Core Python concepts and programming logic using a real-world movie ticket booking scenario.
